## Decisions and corrections

Keep the internal/assistant-draft label near results, and full qualification boundaries in methodology. Remove the prominent zero counter and research-question hero. Keep unknown costs and failed/blocked assignments visible, and do not pool historical adapter checks with procurement verification.

There are 324 assigned API request slots across the entire current cohort, of which 306 were dispatched, 299 completed, seven failed/incomplete and 18 were blocked before dispatch. The 18 blocked slots belong to one Sakana configuration. Separately, each model has 324 assigned probe judgments. These identical numbers have different units. Gemini's initial denominator wording and Qwen's "18 blocked models" wording are not adopted.

The Pareto view uses verification-only charges/latency and agreement with the fixed draft labels, within the selected case scope. A configuration with unknown cost is omitted from the cost view with an exclusion count, never priced at zero. This is an observed descriptive frontier, not evidence of superiority. Top cases include all ties at the tenth boundary. Three repetitions are displayed as variability, not model progress over time. Latest-tested timestamps are not provider release dates; no release ranking is fabricated.

No universal kappa threshold, epsilon threshold or all-calls-must-complete requirement is adopted from a model suggestion. The frozen qualification protocol, independent domain annotation/adjudication, custody and reproducibility requirements remain authoritative. An adversarial model can find counterexamples; it cannot turn a maintainer-run diagnostic into independent validation.
