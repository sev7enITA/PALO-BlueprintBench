# BlueprintBench semantics

Version 0.1.0 provides an additive vocabulary for evaluation programmes, model configurations, cohorts, runs, measurements, blueprints and reviews.

- [Dictionary](data/blueprintbench-vocabulary.json): definitions and eight dimensions.
- [Taxonomy](formal/palo-blueprintbench-taxonomy.ttl): SKOS concepts for dimensions, evidence provenance, qualification and index availability.
- [Ontology](formal/palo-blueprintbench-ontology.ttl): OWL classes and relationships linked to the existing PALO vocabulary.
- [Verification](verification.json): scoped parse, reference and publication checks.

PALO Blueprint Index is a proposed index definition. No score, formula, weights or IndexResult instance is asserted. Evidence provenance and qualification are separate axes. These vocabularies describe meaning; they do not execute qualification checks.

Published guidance: [taxonomy and dictionary](https://paloframework.org/docs/palo-agentic-taxonomy-and-dictionaries.html), [ontology](https://paloframework.org/docs/palo-agentic-ontologies.html), [Platform Map](https://paloframework.org/PALO_PlatformMap.html). The digest-bound PALO 3.1 core is unchanged.
