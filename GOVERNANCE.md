# Project governance

This is a maintainer-led research pilot, not an accredited institution or an independent standards body.

## Current responsibility

Fabrizio Degni maintains the repository and PALO Workbench. The same party developing and evaluating the system is a conflict of interest. Model consultations, including GLM, Gemini and a local model, are advisory and do not establish independent validation.

## Proposed independent roles

Domain annotators prepare references without seeing system outputs. Adjudicators resolve documented disagreements. Reproducers execute frozen configurations and inspect receipts. Business participants measure actual review effort, including adding omitted facts. These roles are being recruited; none is represented as already appointed.

## Decisions and appeals

Method changes start as public RFCs. Publish the rationale, dissent, sensitivity analysis and affected versions before adopting a new score or eligibility gate. Evidence corrections use a dated correction log; original artifacts remain identifiable. A submission can be challenged by opening an issue with public evidence and a precise reproduction path. Never attach confidential documents or active answer keys.

Independent claims require named scope and evidence of independence. Sponsorship, provider credits, maintainer tuning and reproduction relationships must be disclosed per campaign. An outside reviewer must not approve a submission in which they have an undisclosed interest.

## Release authority

The maintainer currently publishes pilot releases. Release labels distinguish synthetic tests, development diagnostics, comparable candidates and qualified independently evaluated results. Only the first two are available now. No admission to a future ranking is automatic.
