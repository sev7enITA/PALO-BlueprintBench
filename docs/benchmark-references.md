# Benchmark references

These references compare documented tasks, evidence and evaluation practices, not model scores. PALO differences and transfer priorities are maintainer assessments, not claims of superiority or exclusive novelty. External suites were not executed. Sources checked 2026-11-11.

35 references: the original 20, including all 12 entries in [terryyz/llm-benchmark](https://github.com/terryyz/llm-benchmark/blob/ffe4975fbdefd922136ae6311ac1beee480a9b0d/README.md), plus 15 high-visibility benchmark families. Dataset libraries, harnesses, platforms and task benchmarks have different roles.

## Selection and visibility

Purposive high-visibility selection using official model-launch references, dedicated public leaderboards/competitions and dated GitHub repository participation. At least one source-backed visibility signal is required per added family.

Not an exhaustive ranking of global hype, social reach or benchmark quality. No comparable social/media time series was collected. Repository stars are cumulative attention proxies with age and project-scope bias; the Gorilla count is parent-project-wide. Different benchmark versions remain separate. No external suite was executed.

Direct: transferable to business workflow, evidence or operational checks. Method: useful evaluation design. Context: broad capability context. These are maintainer assessments, not external validation.

[Dated repository snapshots](reference-visibility-signals.json) preserve the API sources. No popularity or quality score is calculated.

## PALO today

**Implemented:** Evidence schema, annotation consistency, raw-output binding, calculated task acceptance, structural replay and historical configuration explorer. The public dashboard includes 18 internal model configurations, metric-specific exploratory ranks and separate automated countertests; labels remain assistant drafts.

**Proposed study:** Procurement specification-fidelity study, independently adjudicated unseen cases, critical-rule inversion analysis and measured human correction effort.

**Open qualification work:** External preregistration/custody, independent annotation, metric calibration, proposition-bank reuse and family-aware uncertainty.

Qualified held-out results: **0**. No PALO Blueprint Index score is assigned. References imply no affiliation, endorsement or operational integration.

## Transfer priorities

### Expert gold and atomic rubrics

Recruit procurement experts, freeze allowed alternatives and forbidden inferences, adjudicate disagreements and report human agreement before qualification.

References: GDPval, DeepResearch Bench / II, GPQA / Diamond. These are proposed actions, not completed qualification.

### End-to-end workflow reliability

Test document import, interpretation, human correction and blueprint export with repeated runs, environment identity, failure states and cost/time accounting.

References: tau2-bench, OSWorld, Terminal-Bench. These are proposed actions, not completed qualification.

### Separate structural and semantic evidence

Report schema/tool validity, source support, semantic violations and downstream executable checks as separate outcomes.

References: Berkeley Function Calling Leaderboard, SWE-Bench Pro, BrowseComp. These are proposed actions, not completed qualification.

### Freshness, custody and disclosure

Use externally selected unseen families, date windows, protected answer custody, sponsor/data-access disclosures and versioned judge/adapter policies.

References: LiveCodeBench, Humanity's Last Exam, ARC-AGI, FrontierMath. These are proposed actions, not completed qualification.
