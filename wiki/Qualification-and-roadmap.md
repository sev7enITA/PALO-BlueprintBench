# Qualification and roadmap

## Current release

The code can check bounded evidence consistency and calculate acceptance. It cannot certify independent annotations or infer institutional authority from a JSON declaration. There are **zero qualified held-out entries** and no PBI score.

## Gates before a qualified comparison

1. **Independent source families:** scope, rights, exposure and split decisions recorded before evaluation.
2. **Blinded reference preparation:** domain annotators and an adjudicator agree meanings, legitimate alternatives and critical rules before seeing system outputs.
3. **External commitment:** an appointed custodian acknowledges exact commitments through a verifiable record with independent timing.
4. **Metric calibration:** seeded semantic defects, valid controls, detection, false alarms and disagreements are evaluated separately from tuning.
5. **Comparable execution:** frozen configurations, all assigned attempts, failure accounting and complete cost disclosures.
6. **Uncertainty and human effort:** family-aware analysis, correction sessions and limits on any ranking inference.
7. **Independent decision:** identified domain and reproduction reviewers sign the exact scope, digests, conflicts, limitations and appeal route.

These gates are planned work. A public Git tag or a custodian's receipt alone does not validate semantic quality. No external board or custodian appointment is claimed.

## Open technical work

Persistent proposition-bank reuse, external registration verification, family-aware aggregation/uncertainty and a validated human-effort workflow remain open. RFC 8785 serialization is not implemented. The eight-dimensional PBI composite is a proposal, not an available score.

## Independence

The maintainer also develops PALO Workbench. This conflict is disclosed and requires independent participation; separate branding does not remove it. Model consultations are advisory. The maintainer cannot replace missing independent approval with a self-issued decision.
